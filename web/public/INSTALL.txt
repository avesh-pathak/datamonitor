DATA MONITOR FOR WINDOWS 11 — INSTALLATION & QUICK START GUIDE
================================================================================
Version:      0.1.0
Author:       Avesh Pathak (https://avesh.tech)
Source:       https://github.com/avesh-pathak/datamonitor
License:      MIT
Requirements: Windows 11 (64-bit), PowerShell 5.1+, Active Network Adapter

--------------------------------------------------------------------------------
OPTION 1: INSTALL VIA EXECUTABLE (.EXE) — RECOMMENDED FOR ALL USERS
--------------------------------------------------------------------------------
1. Download the latest installer:
   File: Data-Monitor-Setup.exe (or Data-Monitor-Portable.exe)
   URL:  https://github.com/avesh-pathak/datamonitor/releases/latest

2. Run the installer:
   - Double-click 'Data-Monitor-Setup.exe'.
   - Choose your install location (or accept the default).
   - Check "Create Desktop Shortcut" if desired.
   - Click "Install".

3. Launch:
   - The speedometer readout will immediately anchor itself into your Windows 11
     taskbar beside the system tray.
   - Click the taskbar readout at any time to open the full Analytics Dashboard.
   - Right-click the system tray icon to switch dark/light theme, pause, or quit.

--------------------------------------------------------------------------------
OPTION 2: RUN FROM SOURCE (DEVELOPERS)
--------------------------------------------------------------------------------
1. Clone the repository:
   git clone https://github.com/avesh-pathak/datamonitor.git
   cd datamonitor

2. Run directly from root:
   npm install --prefix app
   npm start

   Or navigate into the app folder:
   cd app
   npm install
   npm start

3. Build your own .exe installer:
   npm run dist --prefix app
   (The installer will be generated inside app/dist/)

--------------------------------------------------------------------------------
HOW TO START AUTOMATICALLY AT WINDOWS LOGIN
--------------------------------------------------------------------------------
If using the installer (.exe):
   - The installer can register a shortcut during setup.
If running portable or from source:
   - Press Win + R, type 'shell:startup' and press Enter.
   - Right-click and choose "New -> Shortcut".
   - Set Target to: "C:\path\to\Data-Monitor.exe"
   - Click Finish.

--------------------------------------------------------------------------------
PRIVACY & SYSTEM FOOTPRINT
--------------------------------------------------------------------------------
- Telemetry:           ZERO. No analytics, no crash reports, no network calls.
- Admin rights:        NOT required. Runs in standard user space.
- Configuration file:  %APPDATA%\taskbar-data-monitor\settings.json
- Uninstallation:      100% clean. Delete the directory/shortcut or use Windows
                       Settings -> Apps -> Installed apps -> Uninstall.
